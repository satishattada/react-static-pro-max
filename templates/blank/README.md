# React Static Pro Max - Blank Template

A minimal blank template for React Static Pro Max.

## Getting Started

```bash
npm install
npm start
```

## Available Commands

- `npm start` - Start the development server
- `npm run build` - Build for production
- `npm run export` - Export static site
- `npm run serve` - Serve the built site locally

Visit [React Static Pro Max Documentation](https://github.com/satishattada/react-static-pro-max) for more information.
